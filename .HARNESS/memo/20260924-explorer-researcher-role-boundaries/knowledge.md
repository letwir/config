# knowledge | 20260924-explorer-researcher-role-boundaries

Explorer and Researcher are now separate by search breadth and output purpose. Explorer is an on-demand high-recall scout for stuck/sparse/repetitive investigations; topic similarity and source precision do not filter leads, but every lead carries source, relation, and confidence/verification labels, and Explorer makes no adoption recommendation. Researcher remains scoped to the current task and compares applicable documentation, references, existing OSS, and technical blogs, returning candidate methods with applicability, prerequisites, usage, side effects, and source quality/confidence. Routing, TOML descriptions, Markdown protocols, LRF roles, README index, and `etl/research.seq` output fields were synchronized. Static verification: agents, etl, and rules harness-lint level 2 all had no diagnostics; all 8 TOMLs parsed with unique names; scoped diff check clean.
