# 国土交通省データプラットフォーム (MLIT DPF) 検索スキル

Windows環境において、国土交通省のデータプラットフォーム（MLIT DPF）に対してGraphQL経由で様々なインフラや地域データを検索・取得するための統合スキルですわ。
実行可能バイナリ **`kokkou.exe`** を使用して動作いたします。

## 実行環境とパス
- **バイナリパス**: `C:\Users\letwir\.gemini\config\plugins\ltw-skills-plugin\skills\kokkousyou-api\kokkou.exe`
- **シェル制限**: 必ず Windows 上の `pwsh` で実行してくださいませ。

## コマンドライン引数仕様

エージェントがコマンドを実行する際は、必要に応じて以下の引数を組み合わせて呼び出してください。引数の指定順序は自由ですわ。

| 引数・オプション | タイプ | デフォルト | 説明 |
| :--- | :---: | :---: | :--- |
| **位置引数（第1引数）** | `string` | なし | 検索キーワード (例: `"橋梁"`, `"トンネル"` など) |
| `-c` / `--count` | `flag` | なし | 検索にヒットした **総件数 (数値のみ)** を標準出力に出力して即時終了します。LLMがヒット件数だけを知りたい時にトークン節約として極めて有効です。 |
| `--around <lat,lon,dist>` | `string` | なし | 空間検索。中心点の緯度・経度と半径（メートル）を指定します。 (例: `--around 35.6895,139.7001,1000` で新宿周辺1km以内を検索) |
| `-d` / `--dataset <id>` | `string` | なし | 特定のデータセットIDでフィルタリングします。 (例: `rsdb_bridge`) |
| `-p` / `--prefecture <name>` | `string` | なし | 都道府県名でフィルタリングします。 (例: `"東京都"`, `"北海道"`) |
| `-j` / `--json` | `flag` | なし | 検索結果を人間向けのテキストではなく、パースしやすい **生JSON配列** で出力します。LLMがデータを読み取る際は必ずこのフラグを付与してください。 |
| `--limit <int>` | `int` | `10` | 取得する最大件数。指定しない場合はデフォルトで10件返却されます。 |

## 具体的な使用例
```powershell
# Get the skill directory path
$skillDir = "$env:USERPROFILE\.gemini\config\plugins\ltw-skills-plugin\skills\kokkousyou-api"
```

### 1. キーワードによる基本検索 (人間向けテキスト表示)
```powershell
& "$skillDir\kokkou.exe" "橋梁" --limit 5
```

### 2. 特定地域かつ特定のインフラの「件数のみ」を取得 (超軽量・推奨)
「北海道にトンネルはいくつあるか？」という質問に答える際、何百件もの詳細データを受信せず、件数数値だけを即座に取得できますわ。
```powershell
& "$skillDir\kokkou.exe" "トンネル" -p "北海道" -c
# 出力例: 786
```

### 3. 特定座標の周辺インフラを最大3件 JSON で取得する
「新宿周辺の半径100m以内にどのような国土交通データがあるか？」を調査する例ですわ。
```powershell
& "$skillDir\kokkou.exe" --around 35.6895,139.7001,100 --limit 3 -j
```

### 4. 特定データセットから特定の都道府県に絞り込んでJSONパースする
```powershell
& "$skillDir\kokkou.exe" "橋梁" -p "京都府" -d "rsdb_bridge" -j
```

## 注意事項
- このスキルを実行するには、Windows環境変数またはレジストリに有効な **`KOKKOU_API`** (MLIT DPF APIキー) が設定されている必要がありますわ。
- コマンドは `pwsh` で `& "$skillDir\kokkou.exe" ...` の形式で呼び出してくださいませ。
