# Real Estate Information Library API Client Skill

## Overview
国土交通省「不動産情報ライブラリ」のAPIを操作し、不動産の取引価格情報や都道府県内の市区町村一覧を取得するSKILLですわ。
実行にあたっては、環境変数 `KOKKOU_HUDOUSAN_API` またはWindowsのユーザー環境変数（レジストリ）にAPIキーが設定されている必要がありますの。

## Usage
バイナリ `hudousan.exe` は以下の引数を受け取りますわ。

```powershell
hudousan.exe [オプション]
```

### Options
- `-price`: 不動産価格（取引価格・成約価格）情報取得API (XIT001) を呼び出すフラグ。
- `-list`: 都道府県内市区町村一覧取得API (XIT002) を呼び出すフラグ。
- `-area`: 都道府県コード (例: `13` - 東京都)。
- `-year`: 取引年 (例: `2024` - `-price` 実行時に必須)。
- `-quarter`: 四半期 (例: `1` - 1~3月, `2` - 4~6月, `3` - 7~9月, `4` - 10~12月)。
- `-city`: 市区町村コード (例: `13102` - 中央区)。
- `-station`: 駅コード。

### Examples
```powershell
# Get the skill directory path
$skillDir = "$env:USERPROFILE\.gemini\config\plugins\ltw-skills-plugin\skills\hudousan-api"
```
#### 1. 都道府県内の市区町村一覧を取得する
```powershell
"$skillDir\hudousan.exe" -list -area 13
```

#### 2. 特定の年・四半期・都道府県の不動産取引価格情報を取得する
```powershell
"$skillDir\hudousan.exe" -price -year 2024 -quarter 1 -area 13
```

#### 3. 特定の市区町村の不動産取引価格情報を取得する
```powershell
"$skillDir\hudousan.exe" -price -year 2024 -city 13102
```
