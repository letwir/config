 [AFLOW] AFLOW/AFLUX REST API :: species/composition → spacegroup/enthalpy/thermodynamics | req:none
 [PubChem] PubChem PUG-REST API :: compound_name/smiles → MW/IUPAC/SMILES/NMR_IR_Spectra_Link | req:none(SDBS_alt)
 [IEEE] IEEE Xplore API :: query → engineering/physics/cs_articles/abstract/doi | req:IEEE_API_KEY
 [ADS] NASA ADS API :: query → astrophysics/physics/bibcode/abstract/doi | req:ADS_API_TOKEN
 [COD] Crystallography Open DB :: formula → lattice_params/spacegroup/cif_download | req:none
</api_registry>

<exec_mode>
 Dispatcher: `rikei.exe <cmd> [query]`
  - `rikei.exe search <query>` (Cross-domain unified search)
  - `rikei.exe mp <formula>` (Materials Project query)
  - `rikei.exe aflow <species>` (AFLOW/AFLUX query)
  - `rikei.exe pubchem <name>` (PubChem physchem query)
  - `rikei.exe ieee <query>` (IEEE Xplore query)
  - `rikei.exe ads <query>` (NASA ADS query)
  - `rikei.exe cod <formula>` (COD CIF query)
 SubBinaries: Direct execution via `mp-search.exe`, `aflow-search.exe`, `pubchem-search.exe`, etc.
</exec_mode>
