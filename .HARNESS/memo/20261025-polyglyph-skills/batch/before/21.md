# llama2coder Skill

This skill allows the agent to generate clean source code snippets directly to stdout without explanations, intro/outro text, or markdown code blocks (unless explicitly requested). It communicates with a running `llama-server` (or compatible OpenAI REST API) backend.

## Location & Structure
- **Binary**: `C:\Users\letwir\.gemini\config\plugins\ltw-skills-plugin\skills\llama2coder\coder-*.exe` (Search via `lsd.exe coder-*`)
- **Source Code**: `C:\Users\letwir\.gemini\config\plugins\ltw-skills-plugin\skills\llama2coder\src/`

## Usage Instructions

First, use `lsd.exe` to find the exact binary name in the skill directory:
```powershell
lsd.exe C:\Users\letwir\.gemini\config\plugins\ltw-skills-plugin\skills\llama2coder\coder-*
```
Then, use the matched binary (e.g. `coder-gpu2.exe`) directly in a PowerShell console to query the model for code generation.

### Command Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--prompt` | `-p` | (Required) | The user instruction / task description. |
| `--language`| `-l` | `python3` | Target programming language. |
| `--url` | `-u` | `http://localhost:8080` | llama.cpp API Base URL. |
| `--model` | | `default` | Model identifier. Required for some API endpoints. |
| `--stream` | `-s` | `false` | Stream tokens directly to stdout as they generate. |
| `--system` | | `""` | Override the default system prompt. |
| `--temperature` | | `0.2` | Randomness control. |
| `--max-tokens` | | `-1` | Maximum tokens to generate. |

## How it works (Internally)

1. The prompt passed to `--prompt` is enclosed in `<instruction>` XML tags.
2. The default system prompt forces the model to only output raw source code.
3. The client receives the output and performs a cleansing process to filter out markdown fence blocks (such as ` ```python ` and ` ``` `), outputting only the pure code.
