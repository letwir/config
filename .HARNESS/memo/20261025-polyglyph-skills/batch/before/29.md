# Universal HTML Interpreter

## Overview
HTMLファイルから構造化データを抽出するための普遍的なインタープリターですわ。JSON-LD、OGP、メタタグ、そしてDMM/FANZAなどの特定サイト向けの高度な解析ロジックを搭載しておりますの。

## Quick Start
HTMLファイルを解析するには、`scripts/interpret.go` を使用いたします。

```powershell
$skillDir = "$env:USERPROFILE\.gemini\config\plugins\ltw-skills-plugin\skills\perser-xml"
go run "$skillDir\scripts\interpret.go" <html_file_path>
```

## Tasks

### 1. 普遍的なメタデータ抽出 (Universal Metadata)
`<title>`、`<meta>`、Open Graph Protocol (OGP) タグを網羅的に抽出いたします。
- **対象**: 全てのHTMLページ
- **出力**: `title`, `description`, `site_name`, `ogp` マップなど

### 2. 構造化データ (JSON-LD) の取得
ページ内に含まれる全ての `application/ld+json` ブロックを抽出し、配列として返しますわ。
- **対象**: 商品ページ、記事ページ、レシピなど
- **出力**: `json_ld` オブジェクトの配列

### 3. 特定サイト向けの高度な解析 (Specialized Parsing)
DMM/FANZAなどの特定の構造を持つサイトを自動検知し、メーカー名、品番（SKU）、配信開始日などの詳細情報を抽出いたします。
- **対象**: DMM.co.jp, dmm.com, FANZA関連ページ
