## 概要 (Overview)
`sec-forensics` は、GitHub Dependabot トリアージ、CTF（SECCON / DEFCON AI Village 等）の著名攻撃手法（Unicode Tag Smuggling, SSRF, SSTI, Command Injection, Path Traversal, Polyglot）に対する防御免疫スキャン、プロンプトインジェクション検知、会話ログ Action-Layer フォレンジック、および PostgreSQL (`llm-mem`) と連携した動的 CVE/CTF 知識フェッチ＆`mega-doc-update` 統合セキュリティゲートを提供する CLI ツールです。

## 使用方法 (Usage)

### 1. 調査前 CVE / CTF 攻撃インテリジェンスの取得 (PIF: Pre-Investigation Fetch)
```powershell
& "$env:USERPROFILE\.gemini\config\plugins\ltw-skills-plugin\skills\sec-forensics\sec-forensics.exe" cve-fetch -query "pillow"
```

### 2. CTF / SECCON / DEFCON 著名攻撃手法に対する免疫スキャン
```powershell
& "$env:USERPROFILE\.gemini\config\plugins\ltw-skills-plugin\skills\sec-forensics\sec-forensics.exe" scan-ctf -file "path/to/document.md"
```

### 3. mega-doc-update 包括セキュリティ・免疫ゲート
```powershell
& "$env:USERPROFILE\.gemini\config\plugins\ltw-skills-plugin\skills\sec-forensics\sec-forensics.exe" mega-check -repo "letwir/flac_analyzer_forwin" -docs "C:\Users\letwir\.gemini"
```

### 4. 初期セキュリティナレッジの投入 (Seeding)
```powershell
& "$env:USERPROFILE\.gemini\config\plugins\ltw-skills-plugin\skills\sec-forensics\sec-forensics.exe" cve-ingest -seed
```
